# 城市公共篮球场 · 预约拼场照明计费与冲突调解

基于 **Vue 3 + TypeScript + Naive UI** 的移动端优先单页应用，覆盖公共篮球场「预约 → 拼场 → 现场核验 → 照明计费 → 冲突调解 → 公平公示」全流程。

## 本地启动

```bash
npm install        # 如 npm 缓存目录无权限：npm install --cache /tmp/npm-cache
npm run dev        # 开发服务器，默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建（vue-tsc --noEmit && vite build）
npm run preview    # 预览生产构建
```

建议用浏览器开发者工具的手机模式（如 iPhone 14）访问，页面按 ≤520px 窄栏设计。

## 功能地图

- **场地**：3 片场地，展示地面状况、篮筐维修、噪声敏感小区、更衣柜余量、照明费率与今日时段占用；降雨/维修预警横幅。
- **预约**：场地/日期/连续时段/半场全场/人数/是否接受拼场/是否夜间照明；费用预估（场地免费 + 照明押金 ¥30 + 预估照明费）；黄金时段每周限约 3 次的公平性拦截。
- **拼场**：开放场次列表（已有/还可加人数），散客申请 → 队长确认 → 凭同一核验码签到；拼场成功照明费按人数分摊。
- **现场**：当前时段「谁该在场 + 还能打多久」倒计时、核验状态、照明计费实时预览；核验码签到（队长首签自动开灯）；一键上报下雨/维修/争抢篮筐/噪声/未成年人滞留/照明故障；队长可提前离场结算或拒绝拼场（触发处罚）；管理员可开关灯、强制清场、封场。
- **事件**：事件详情把关联预约权益、现场核验记录、退款补偿、投诉时间线、后续处罚串在一起；管理员结案可执行退款与处罚。
- **我的**：信用分、我的预约（核验码/队员签到/邀请队员/拼场审批/取消）、全部账单。
- **后台**（管理员）：今日概览 + 分场地时段表（预约人数/实际到场/支付状态/冲突风险等级及原因），时段详情与取消、封场操作。
- **公平性**：黄金时段使用分布（固定球队/散客拼场/周边居民）、改约与限制留痕（引用规则条款）、全部计费与分配规则公示。

## 计费规则（种子数据可直接演示）

- 照明按实际开启时长计费，不满 30 分钟按 30 分钟计；迟到 >15 分钟自预约开始时间起计；超时部分 1.5 倍；提前离场按实际时长；押金 ¥30 多退少补；现场拒拼扣押金 50% + 信用 -15。
- 「我的 → 全部账单」中预置了三个昨日已完成场次，分别演示 **迟到+超时**、**提前离场退押金**、**拒绝拼场处罚** 的账单。
- 现场页/后台页的「演示时钟」可 ±15 分钟推进时间，用于演示开灯计费、爽约判定（开场 30 分钟未签到）、超时计费等动态过程。

## 验证方式（本仓库已实际执行的验证）

1. `npm run build` —— vue-tsc 类型检查 + vite 生产构建通过（2705 个模块）。
2. `npm run dev` 启动后，`curl` 验证首页与全部 8 个视图模块、store、计费引擎均返回 200 且可编译。
3. 计费引擎数值测试（esbuild + node 直接调用 `src/fee.ts`）：
   - 迟到 20 分钟 + 超时 25 分钟（全场）：常规 120 分钟 ¥40 + 超时 ¥15 = ¥55，押金 ¥30 需补 ¥25；
   - 提前离场（半场，照明 65 分钟）：按 90 分钟计 ¥18，退押金 ¥12；
   - 现场拒拼（全场）：照明 ¥48 + 罚金 ¥15 = ¥63，需补 ¥33；
   - 拼场分摊（10+1 人）：队长方承担 ¥36.36，拼场方 ¥3.64。

## 建议手工走查路径

队长视角「我的」处理拼场申请 → 散客视角「拼场」看到已确认与核验码 → 「现场」输入核验码签到 → 推进演示时钟观察照明计费与倒计时变化 → 管理员「后台」查看到场人数与冲突风险、执行封场 → 「事件」结案退款 → 「公平性」查看留痕。
